# SakuraQR 樱花二维码树

把一个短网址种成一棵可 3D 打印的方块樱花树。从侧面看是一棵像素风樱花树，从正上方看，树冠顶面就是一个能扫的二维码。树倒过来打印（码面贴平台），底座单独打印，插上就行，都不需要支撑。

在线使用：<https://kirikira.github.io/SakuraQR/>

每次推送到 `main`，GitHub Actions 会先跑冒烟测试，再把站点发布到 `gh-pages` 分支，由 GitHub Pages 提供访问。

## 怎么用

1. 输入网址（默认 `https://muque.jp`），调树形和配色。
2. 看左侧扫描器：“正俯视”和“手机”都显示可识别再导出。
3. 点“下载俯视图 PNG”，先用手机扫一下，确认网址能正常打开。
4. 点“下载 3MF（多色）”，导入 Bambu Studio / OrcaSlicer 或 PrusaSlicer，给树的每个部件指定耗材后切片打印，不用开支撑。文件已经按打印摆好：树倒置、码面朝下，旁边是底座（另一个物体，可以用别的颜色）。PrusaSlicer 问是否作为多部件物体载入时选“是”。只能用单色 STL 的切片软件可以下载“STL（按颜色分件）”。
5. 打完把树翻过来，树干末端的方榫插进底座的方孔。插不进就把“插口间隙”调大重打底座，太松就点一滴胶。

## 设计思路

- **先设计树，再给顶面上色。** 树形按像素画樱花的画法生成：短粗树干分叉成几根主枝，托起几团底部平、边缘收圆的花云。二维码只决定树冠顶面每一格的颜色：深色码点保持花的颜色，浅色码点染成浅粉高光。
- **整个码在一个平面上。** 手机是透视成像，码点之间的高度差会让码错位。主枝朝码的四个角伸，树冠顶面平整，把包括三个码眼在内的整个码托住，码点之间没有高差，手机远近、偏不偏离中心都能扫。
- **倒过来打印。** 正着打，树冠下面全是悬空的台阶，切片软件会把四成以上的耗材用在支撑上。倒过来，平整的顶面就是贴平台的第一层（码面最平、颜色最清楚），花云从顶面往下挂，每一列方块都压在上一层的方块上；主枝每一级台阶的内侧补一块 45° 倒角；树干朝上，末端是 8 mm 见方的榫头。底座单独正着打，中间是方孔。树和底座都不需要支撑。
- **短网址用字母数字模式。** 网址的协议和域名不区分大小写，`HTTPS://MUQUE.JP` 可以用 QR 的字母数字模式，放进最小的 21×21（版本 1），还能用 Q 级 25% 纠错。带区分大小写的路径时会自动保持原样。
- **自选掩码。** QR 的 8 种掩码都能扫，自动模式挑树冠顶面零碎孤点最少的那种。
- **打印规则写进生成过程。** 生成时就保证倒置后每一列花云从顶面连续往下、中间不断开，断开处以下的花块削掉；其余上方空着的方块（主枝内侧、树根）都配一块 45° 倒角。

## 导出文件

| 文件 | 内容 |
|---|---|
| `.3mf` | 按打印摆好的两个物体，单位毫米：树（倒置，码面在 z = 0，每种颜色一个部件：花、高光、树干），和旁边的底座。树是翻转过来的，不是镜像，翻回来俯视时码的方向正确。 |
| `-stl.zip` | 同样的部件，每种颜色一个二进制 STL，外加底座的 STL。 |
| `-top.png` | 正俯视的像素图，带白边，用来先扫一遍。 |

每个颜色部件都是封闭外壳（没有开放边），倒角块侧面按对角线切成的三角形和相邻方块严丝合缝。同色方块只在棱上相接的地方会有一条边被四个面共用，和 MagicaVoxel 导出的模型一样，主流切片软件可以正常处理。

榫头比树干短 0.4 mm（7.6 mm），底座 8 mm 厚，方孔每边比榫头宽“插口间隙”（默认 0.2 mm）。

## 打印建议

- 默认 4 mm 方块，`https://muque.jp` 的成品插上底座约 124 × 124 × 112 mm；树和底座各 124 mm 见方，可以并排放进 256 mm 的打印平台，放不下就让切片软件自动排布或分两盘。
- 不用开支撑。按 OrcaSlicer（Bambu X1C 配置）和 PrusaSlicer（自动阈值、30° 阈值）切片，支撑都是 0。
- 码面贴着平台打，表面质感由平台决定：纹理 PEI 是哑光的，反光少，更好扫。
- 树冠内部是实心的，切片时用 10–15% 稀疏填充即可。
- 两种粉色只在贴平台的那一个方块厚度（约 20 层）里同时出现，往上基本只有花色和树干色。单喷头 AMS 的换色从正着打的约 300 次降到约 60 次（默认网址，0.2 mm 层高）。
- 深浅两种粉的灰度差要足够大（页面会显示），浅粉和白色太接近时容易扫不出来。

## 本地运行

纯静态页面，不需要构建：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

3D 预览用 three.js r128，浏览器内解码用 jsQR，都从 CDN 加载。二维码编码器（`js/qr.js`）是自己实现的，支持版本 1–6、字节和字母数字模式、四种纠错等级和任意掩码。

## 测试

```sh
node test/smoke.js
```

无依赖的冒烟测试：编码 `HTTPS://MUQUE.JP` 等几个网址，生成树，按倒置的打印方向检查免支撑（所有方块和倒角都连到平台、每个方块下面都有方块或倒角、每块倒角都靠在方块上、码点全部在顶面上），导出 3MF 和 STL，检查每个部件没有开放边、榫头和插口尺寸对得上，并把俯视图写成 `test/out/topview.ppm`，可以用任意二维码解码器确认能扫。

## 代码结构

```
index.html      页面和样式
js/qr.js        二维码编码器
js/tree.js      樱花树生成器（树形、挂在顶面下的花云、主枝和倒角、顶面上色）
js/export.js    3MF / STL / ZIP / 俯视图导出（按打印方向的树、榫头和底座）
js/app.js       界面、3D 预览、扫描模拟
test/smoke.js   冒烟测试
```
