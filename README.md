# SakuraQR 樱花二维码树

把一个短网址种成一棵可 3D 打印的方块樱花树。从侧面看是一棵像素风樱花树，从正上方看，树冠顶面就是一个能扫的二维码。

在线使用：<https://kirikira.github.io/SakuraQR/>

每次推送到 `main`，GitHub Actions 会先跑冒烟测试，再把站点发布到 `gh-pages` 分支，由 GitHub Pages 提供访问。

## 怎么用

1. 输入网址（默认 `https://muque.jp`），调树形和配色。
2. 看左侧扫描器：“正俯视”和“手机”都显示可识别再导出。
3. 点“下载俯视图 PNG”，先用手机扫一下，确认网址能正常打开。
4. 点“下载 3MF（多色）”，导入 Bambu Studio / OrcaSlicer 或 PrusaSlicer，给每个部件指定耗材后切片打印，不用开支撑。PrusaSlicer 会问“是否作为一个有多个部件的物体载入”，选“是”。只能用单色 STL 的切片软件可以下载“STL（按颜色分件）”。

## 设计思路

- **先设计树，再给花尖上色。** 树形按像素画樱花的画法生成：短粗树干在中段分叉，主枝托起几团底部平、顶部蓬起的花云。二维码只决定每一列最顶上那一格的颜色：深色码点保持花的颜色，浅色码点染成浅粉高光。
- **整个码放在树冠顶上。** 手机是透视成像，码点之间的高度差会让码错位。四根主枝朝四个角伸，树冠把包括三个码眼在内的整个码托在一个微微拱起的顶面上，高差只有一两厘米，模拟手机在 40 cm 到 1.5 m 都能识别。
- **短网址用字母数字模式。** 网址的协议和域名不区分大小写，`HTTPS://MUQUE.JP` 可以用 QR 的字母数字模式，放进最小的 21×21（版本 1），还能用 Q 级 25% 纠错。带区分大小写的路径时会自动保持原样。
- **自选掩码。** QR 的 8 种掩码都能扫，自动模式挑树冠顶面零碎孤点最少的那种。
- **打印规则写进生成过程，切片软件只看到 45° 斜面。** 每个方块要么压在下面的方块上，要么只往外（或斜着）悬出 1 格；悬出的那格底下补一块 45° 倒角（楔块、两个楔块拼成的内角，或接住斜向悬挑的外角块），所以没有平着悬空的面，不需要支撑。树枝按 45° 斜着长，每团花云收在从自己枝头往上张开的 45° 锥里。托着二维码的方块不削，下面缺支撑时往最近的枝或花云补一根 45° 的花撑；其余挂不住的花块削掉。“2 格 / 3 格”悬挑的树冠更圆，但会有 8–12 mm 平着悬空的台阶，要开支撑。

## 导出文件

| 文件 | 内容 |
|---|---|
| `.3mf` | 每种颜色一个部件（花、高光、树干），组合成一个物体，单位毫米，底面在 z = 0。俯视时二维码方向正确，不是镜像。 |
| `-stl.zip` | 同样的部件，每种颜色一个二进制 STL。 |
| `-top.png` | 正俯视的像素图，带白边，用来先扫一遍。 |

每个颜色部件都是封闭外壳（没有开放边）：方块之外还有 45° 倒角块，侧面按对角线切成的三角形和相邻方块严丝合缝。同色方块只在棱上相接的地方会有一条边被四个面共用，和 MagicaVoxel 导出的模型一样，主流切片软件可以正常处理（PrusaSlicer 报告 manifold = yes）。

## 打印建议

- 默认 4 mm 方块，`https://muque.jp` 的成品约 124 × 124 × 104 mm。
- 不用开支撑。倒角都是 45°，两个倒角在外角相交的棱线约 35°，FDM 可以直接打。Bambu Studio / OrcaSlicer 默认的 30° 支撑阈值不会在这里加支撑；PrusaSlicer 的“自动”阈值在 0.2 mm 层高下会把这些棱线算成悬垂，要开支撑的话把阈值设成 30°。
- 树冠内部是实心的，切片时用 10–15% 稀疏填充即可。
- 浅粉花尖分布在树冠顶面的几层高度里，单喷头 AMS 要换几百次色；双喷头或换头打印机基本没有冲刷浪费。
- 深浅两种粉的灰度差要足够大（页面会显示），浅粉和白色太接近时容易扫不出来。

## 本地运行

纯静态页面，不需要构建：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

3D 预览用 three.js r128，浏览器内解码用 jsQR，都从 CDN 加载。二维码编码器（`js/qr.js`）是自己实现的，支持版本 1–6、字节和字母数字模式、四种纠错等级和任意掩码。

## 测试

```sh
node test/smoke.js
```

无依赖的冒烟测试：编码 `HTTPS://MUQUE.JP` 等几个网址，生成树，检查免支撑打印的规则（所有方块和倒角都连到底座、没有平着悬空的方块、每块倒角都靠在该靠的方块上、码点全部在树冠上），导出 3MF 和 STL，检查每个部件没有开放边，并把俯视图写成 `test/out/topview.ppm`，可以用任意二维码解码器确认能扫。

## 代码结构

```
index.html      页面和样式
js/qr.js        二维码编码器
js/tree.js      樱花树生成器（树形、花云、免支撑规则和 45° 倒角、俯视图上色）
js/export.js    3MF / STL / ZIP / 俯视图导出（方块加倒角块的封闭外壳）
js/app.js       界面、3D 预览、扫描模拟
test/smoke.js   冒烟测试
```
